1. Connexion Google

Importe le JSON d’un client OAuth Application de bureau, puis autorise Google. Le compte déjà ouvert dans Firefox pourra être choisi.

Créer un client OAuth et activer Calendar API · Les étapes Python ne sont pas nécessaires.

Connexion avec PKCE et accès hors ligne. Les autorisations sont mémorisées dans ce profil Firefox. Aucun serveur intermédiaire.

Diagnostic de redirection Firefox

2. Planning My

La session est récupérée automatiquement dans @account quand tu ouvres My. Le refresh token My n’est pas copié : le site renouvelle lui-même sa session.

Dates vides : toute l’année scolaire, de septembre à août, selon la session My. Vide : semestre actuel. Écris 1,2 pour demander les deux semestres si tu y as accès. IDs : 1 lavande, 2 sauge, 3 violet, 4 rose, 5 jaune, 6 orange, 7 cyan, 8 gris, 9 bleu, 10 vert, 11 rouge. Une valeur #RRGGBB choisit la couleur Google la plus proche.

3. Synchronisation

Crée et met à jour les événements dans « Epitech — My ». Les événements absents de My ne sont pas supprimés. Le jour est calculé dans le fuseau Europe/Paris.

Les couleurs My et ton sous-créneau de soutenance ne sont pas présents dans la réponse planning fournie. Les catégories correspondent ici aux modules.
